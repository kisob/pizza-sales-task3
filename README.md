# 🍕 Pizza Place Sales Analysis - Task 3

This project is an Exploratory Data Analysis (EDA) of a pizza place's sales over one year. It was completed as an assignment to demonstrate data manipulation, visualization, and analytical skills using Python in a Jupyter Notebook.

## 📊 Dataset

The dataset contains four CSV files:
- **orders.csv** – Order date and time.
- **order_details.csv** – Quantity and pizza ID per order.
- **pizzas.csv** – Pizza size, price, and type ID.
- **pizza_types.csv** – Pizza name, category, and ingredients.

## 🔍 Analysis Questions

1. What is the total revenue/sales?
2. What is the total quantity sold?
3. What is the total number of orders?
4. How many pizza types do they sell?
5. What is the average price of a pizza?
6. What are the peak hours of sales?
7. What are the total sales made on each day of the week? Which day is the most profitable?
8. What are the top 5 bestselling pizzas?
9. What are the monthly sales trends? Is there any noticeable trend?
10. Which pizza types are underperforming and might need to be removed?

The notebook also includes additional exploratory analysis beyond these questions.

## 🛠️ Tools Used

- Python 3
- Jupyter Notebook
- pandas (data manipulation)
- matplotlib & seaborn (visualization)
- datetime (date/time processing)
